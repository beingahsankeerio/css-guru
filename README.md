# CSS GURU

Writing practice for the SPSC CCE / CSS English papers. Live at https://css-guru.vercel.app

- `src/gym.html`: the app itself (edit this)
- `build.sh`: wraps it into `index.html` with the app manifest and offline support
- `manifest.json`, `sw.js`, `icons/`: what makes it installable and packageable as an Android app
